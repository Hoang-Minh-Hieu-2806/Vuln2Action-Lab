# Reference research paper

The team takes inspiration from published research on LLM-assisted
vulnerability reproduction (CVE -> retrieval -> workflow generation ->
validation). The paper serves as a **conceptual reference** for the pipeline
shape and evaluation mindset.

**Explicit non-claim:** this project does **not** reproduce any paper
completely or exactly. Model choices, datasets, metrics, and lab setups here
are independent, smaller-scale, student-oriented decisions (e.g. rule-based
baseline first, no mandatory T5, no large-scale training).

If the final report compares against paper ideas, it will describe precisely
what was borrowed (pipeline stages, metric names) and what was not
(model weights, datasets, results).
